CSS › Layouts with Flexbox & Grid

Responsive image gallery

A masonry-style gallery using CSS columns: images of different shapes fill the columns and the count adapts to the width.

Working demonstration

View source code of this program 
<!-- HTML -->
<div class="mason"><figure style="aspect-ratio:4/3"><img src="../assets/images/img1.svg" alt="Photo 1"></figure><figure style="aspect-ratio:3/4"><img src="../assets/images/img2.svg" alt="Photo 2"></figure><figure style="aspect-ratio:1/1"><img src="../assets/images/img3.svg" alt="Photo 3"></figure><figure style="aspect-ratio:16/9"><img src="../assets/images/img4.svg" alt="Photo 4"></figure><figure style="aspect-ratio:3/4"><img src="../assets/images/img5.svg" alt="Photo 5"></figure><figure style="aspect-ratio:4/3"><img src="../assets/images/img6.svg" alt="Photo 6"></figure><figure style="aspect-ratio:1/1"><img src="../assets/images/img7.svg" alt="Photo 7"></figure><figure style="aspect-ratio:3/4"><img src="../assets/images/img8.svg" alt="Photo 8"></figure></div>

/* CSS */
.demo .mason { columns: 3 190px; column-gap: .8rem; }
.demo .mason figure { margin: 0 0 .8rem; break-inside: avoid; overflow: hidden; border-radius: 10px; }
.demo .mason img { width: 100%; height: 100%; object-fit: cover; display: block; transition: transform .4s, filter .4s; }
.demo .mason figure:hover img { transform: scale(1.08); filter: brightness(1.1); }
