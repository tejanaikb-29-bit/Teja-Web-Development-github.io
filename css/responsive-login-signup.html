Responsive login and signup page

A split-screen page: a branding panel plus a Login / Sign up form switched with CSS only (radio buttons). Stacks on small screens.

Working demonstration

Welcome to StudyHub

Join thousands of students learning to code, one small project at a time.

View source code of this program 
<!-- HTML -->
<div class="auth">
  <aside class="brand-side"><h3>Welcome to StudyHub</h3><p>Join thousands of students learning to code, one small project at a time.</p></aside>
  <div class="form-side">
    <input type="radio" name="authtab" id="tab-login" checked><input type="radio" name="authtab" id="tab-signup">
    <div class="tabs"><label for="tab-login">Login</label><label for="tab-signup">Sign up</label></div>
    <form class="f-login" onsubmit="return false"><input type="email" placeholder="Email"><input type="password" placeholder="Password"><button>Login</button></form>
    <form class="f-signup" onsubmit="return false"><input type="text" placeholder="Full name"><input type="email" placeholder="Email"><input type="password" placeholder="Create password"><button>Create account</button></form>
  </div>
</div>

/* CSS */
.demo .auth { display: grid; grid-template-columns: 1fr 1.1fr; border-radius: 14px; overflow: hidden; border: 1px solid #ccd5e6; min-height: 430px; }
.demo .brand-side { background: linear-gradient(rgba(20, 33, 61, .78), rgba(20, 33, 61, .78)), url("../assets/images/img5.svg") center / cover; color: #fff; padding: 2rem; display: flex; flex-direction: column; justify-content: center; }
.demo .brand-side h3 { font-size: 1.7rem; margin: 0 0 .6rem; }
.demo .form-side { padding: 1.6rem; background: #fff; }
.demo .form-side > input[type=radio] { display: none; }
.demo .tabs { display: flex; margin-bottom: 1.2rem; border-bottom: 2px solid #e2e8f4; }
.demo .tabs label { flex: 1; text-align: center; padding: .7rem; cursor: pointer; font-weight: 700; color: #55637d; border-bottom: 4px solid transparent; margin-bottom: -2px; }
.demo #tab-login:checked ~ .tabs label[for="tab-login"], .demo #tab-signup:checked ~ .tabs label[for="tab-signup"] { color: #1769b5; border-bottom-color: #1769b5; }
.demo #tab-login:checked ~ .f-signup, .demo #tab-signup:checked ~ .f-login { display: none; }
.demo .form-side input:not([type=radio]) { width: 100%; padding: .7rem .85rem; margin-bottom: .8rem; border: 2px solid #dbe2ef; border-radius: 8px; }
.demo .form-side input:focus { outline: 0; border-color: #1769b5; }
.demo .form-side button { width: 100%; padding: .8rem; background: #1769b5; border-radius: 8px; font-weight: 700; }
@media (max-width: 680px) { .demo .auth { grid-template-columns: 1fr; } .demo .brand-side { padding: 1.2rem; } }
