Inline, internal and external CSS

The same page is styled in three ways: an external stylesheet, an internal <style> block and inline style attributes.

Working demonstration

1. External CSS

Rules come from assets/css/external-demo.css via a <link> tag. Best for sharing styles across many pages.

2. Internal CSS

Rules are written inside a <style> element. Good for a single page.

3. Inline CSS

Rules are in the style attribute. Highest priority, but hard to maintain.

View source code of this program 
<!-- <head> extras -->
<link rel="stylesheet" href="../assets/css/external-demo.css">

<!-- HTML -->
<div class="ext-box"><h3>1. External CSS</h3><p>Rules come from <code>assets/css/external-demo.css</code> via a &lt;link&gt; tag. Best for sharing styles across many pages.</p></div>
<div class="internal"><h3>2. Internal CSS</h3><p>Rules are written inside a &lt;style&gt; element. Good for a single page.</p></div>
<div style="background:#e6f6ec;border:2px solid #178a4a;border-radius:10px;padding:1rem"><h3 style="margin-top:0;color:#11683a">3. Inline CSS</h3><p>Rules are in the <code>style</code> attribute. Highest priority, but hard to maintain.</p></div>

/* CSS */
/* Internal CSS (inside <style> in the <head>) */
.demo .internal { background: #fff1d6; border: 2px solid #d98a00; border-radius: 10px; padding: 1rem; margin: 1rem 0; }
.demo .internal h3 { margin-top: 0; color: #a86400; }
