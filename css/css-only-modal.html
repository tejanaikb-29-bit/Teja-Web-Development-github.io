CSS-only modal / popup

A modal dialog opened and closed with a hidden checkbox and labels, no JavaScript. The overlay fades and the dialog scales in.

View source code of this program 
<!-- HTML -->
<div class="stage"><p>Page content behind the modal.</p>
  <input type="checkbox" id="m-toggle"><label class="open-btn" for="m-toggle">Open modal</label>
  <div class="overlay"><label class="bg-close" for="m-toggle"></label>
    <div class="dialog"><label class="close" for="m-toggle">&times;</label><h3>Subscribe</h3><p>This popup uses only HTML and CSS. Click the &times;, the dark area or the button to close it.</p><label class="ok" for="m-toggle">Got it</label></div></div></div>

/* CSS */
.demo .stage { position: relative; min-height: 300px; border: 2px dashed #b9c3d6; border-radius: 10px; padding: 1rem; overflow: hidden; }
.demo #m-toggle { display: none; }
.demo .open-btn { display: inline-block; background: #1769b5; color: #fff; padding: .6rem 1.2rem; border-radius: 8px; cursor: pointer; font-weight: 700; }
.demo .overlay { position: absolute; inset: 0; background: rgba(20, 33, 61, .65); display: grid; place-items: center; opacity: 0; visibility: hidden; transition: opacity .3s, visibility .3s; }
.demo .dialog { background: #fff; width: min(340px, 90%); border-radius: 12px; padding: 1.4rem; position: relative; transform: scale(.85); transition: transform .3s; }
.demo #m-toggle:checked ~ .overlay { opacity: 1; visibility: visible; } .demo #m-toggle:checked ~ .overlay .dialog { transform: scale(1); }
.demo .close { position: absolute; top: .4rem; right: .8rem; font-size: 1.6rem; cursor: pointer; line-height: 1; }
.demo .bg-close { position: absolute; inset: 0; cursor: default; }
.demo .dialog h3 { margin-top: 0; } .demo .dialog .ok { display: inline-block; background: #178a4a; color: #fff; padding: .5rem 1rem; border-radius: 8px; cursor: pointer; }
