Tooltip using CSS

Tooltips built with a data-tip attribute, ::after and attr(). Hover or focus the elements.

Working demonstration

HTML CSS Below
View source code of this program 
<!-- HTML -->
<div class="tips">
  <span data-tip="HyperText Markup Language" tabindex="0">HTML</span>
  <span data-tip="Cascading Style Sheets" tabindex="0">CSS</span>
  <span class="below" data-tip="Tooltip shown below" tabindex="0">Below</span>
  <button data-tip="Save your work">Save</button>
</div>

/* CSS */
.demo .tips { display: flex; flex-wrap: wrap; gap: 3rem; padding: 3rem 1rem 2rem; }
.demo [data-tip] { position: relative; cursor: help; border-bottom: 2px dotted #1769b5; color: #1769b5; font-weight: 600; }
.demo [data-tip]::after { content: attr(data-tip); position: absolute; bottom: 135%; left: 50%; transform: translateX(-50%) translateY(6px); background: #14213d; color: #fff; padding: .4rem .7rem; border-radius: 6px; font-size: .8rem; font-weight: 400; white-space: nowrap; opacity: 0; visibility: hidden; transition: .2s; }
.demo [data-tip]::before { content: ""; position: absolute; bottom: 115%; left: 50%; transform: translateX(-50%); border: 6px solid transparent; border-top-color: #14213d; opacity: 0; visibility: hidden; transition: .2s; }
.demo [data-tip]:hover::after, .demo [data-tip]:focus::after { opacity: 1; visibility: visible; transform: translateX(-50%) translateY(0); }
.demo [data-tip]:hover::before, .demo [data-tip]:focus::before { opacity: 1; visibility: visible; }
.demo [data-tip].below::after { bottom: auto; top: 135%; } .demo [data-tip].below::before { bottom: auto; top: 115%; border-top-color: transparent; border-bottom-color: #14213d; }
.demo button[data-tip] { border: 0; background: #1769b5; color: #fff; padding: .5rem 1rem; border-radius: 8px; }
