Two-column webpage layout using CSS Grid

A header and footer spanning both columns, with main content (2fr) and a sidebar (1fr) in between.

Working demonstration

Site header (spans both columns)

Main content (2fr)

Articles and the main information of the page go here. The column is twice as wide as the sidebar.

Sidebar (1fr)

Links, ads and related content.

Footer (spans both columns)
View source code of this program 
<!-- HTML -->
<div class="tc"><header><h3 style="margin:0">Site header (spans both columns)</h3></header>
<main><h4>Main content (2fr)</h4><p>Articles and the main information of the page go here. The column is twice as wide as the sidebar.</p></main>
<aside><h4>Sidebar (1fr)</h4><p>Links, ads and related content.</p></aside>
<footer>Footer (spans both columns)</footer></div>

/* CSS */
.demo .tc { display: grid; grid-template-columns: 2fr 1fr; gap: .8rem; }
.demo .tc > * { padding: 1rem; border-radius: 8px; }
.demo .tc header, .demo .tc footer { grid-column: 1 / -1; background: #14213d; color: #fff; }
.demo .tc main { background: #eaf2ff; } .demo .tc aside { background: #fff2c2; }
@media (max-width: 560px) { .demo .tc { grid-template-columns: 1fr; } }
