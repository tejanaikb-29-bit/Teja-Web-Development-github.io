CSS variables (custom properties)

Variables are declared with --name and used with var(). Changing one variable restyles many elements, even on hover.

Working demonstration

Uses the default variables
--brand overridden locally
--space, --radius and --brand overridden

var(--not-defined, hotpink) uses the fallback value

View source code of this program 
<!-- HTML -->
<div class="vars">
  <div class="vc">Uses the default variables</div>
  <div class="vc alt">--brand overridden locally</div>
  <div class="vc big">--space, --radius and --brand overridden</div>
  <button class="vb">Hover: variables change</button>
  <p class="fb">var(--not-defined, hotpink) uses the fallback value</p>
</div>

/* CSS */
.demo .vars { --brand: #1769b5; --radius: 12px; --space: 1rem; --text: #fff; }
.demo .vars .vc { background: var(--brand); color: var(--text); border-radius: var(--radius); padding: var(--space); margin-bottom: var(--space); }
.demo .vars .vc.alt { --brand: #d9481f; }                       /* override for this element only */
.demo .vars .vc.big { --space: 2rem; --radius: 30px; --brand: #178a4a; }
.demo .vars .vb { background: var(--brand); color: var(--text); border: 0; padding: var(--space); border-radius: var(--radius); cursor: pointer; transition: .2s; }
.demo .vars .vb:hover { --brand: #f2c200; --text: #14213d; }    /* variables change on hover */
.demo .vars .fb { color: var(--not-defined, hotpink); font-weight: 700; }   /* fallback value */
