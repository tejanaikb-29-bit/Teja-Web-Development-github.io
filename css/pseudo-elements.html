Pseudo-elements: ::before, ::after, ::first-letter, ::first-line

Pseudo-elements style part of an element or add generated content without extra HTML.

Working demonstration

Generated quotation marks with ::before and ::after

A drop cap uses ::first-letter. The first letter of this paragraph is large and floated to the left, like the opening of a magazine article. The rest of the text flows around it.

The ::first-line pseudo-element styles only the first rendered line of this paragraph, and it changes if you resize the window because the first line changes length. Try it.

External link gets an arrow

Select this text with your mouse to see ::selection.

Ticked using ::before

<!-- HTML -->
<p class="q">Generated quotation marks with ::before and ::after</p>
<p class="drop">A drop cap uses ::first-letter. The first letter of this paragraph is large and floated to the left, like the opening of a magazine article. The rest of the text flows around it.</p>
<p class="fl">The ::first-line pseudo-element styles only the first rendered line of this paragraph, and it changes if you resize the window because the first line changes length. Try it.</p>
<p><label class="req">Required label (::after adds the star)</label></p>
<p class="ext"><a href="https://example.com" target="_blank" rel="noopener">External link gets an arrow</a></p>
<p class="sel">Select this text with your mouse to see ::selection.</p>
<input class="ph" placeholder="::placeholder is styled">
<p class="tick">Ticked using ::before</p>

/* CSS */
.demo .q::before { content: "\201C"; font-size: 2rem; color: #d9481f; vertical-align: -.3em; }
.demo .q::after { content: "\201D"; font-size: 2rem; color: #d9481f; vertical-align: -.3em; }
.demo .drop::first-letter { float: left; font: 700 3.4rem/1 Georgia, serif; color: #1769b5; margin: .1rem .5rem 0 0; }
.demo .fl::first-line { font-weight: 700; color: #178a4a; text-transform: uppercase; }
.demo .req::after { content: " *"; color: #c62828; font-weight: 700; }
.demo .ext a[href^="http"]::after { content: " \2197"; font-size: .8em; }
.demo .sel::selection { background: #f2c200; color: #14213d; }
.demo .ph::placeholder { color: #d9481f; font-style: italic; }
.demo .tick::before { content: "\2714 "; color: #178a4a; }
