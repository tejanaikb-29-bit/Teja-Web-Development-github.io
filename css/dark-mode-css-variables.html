Dark-mode webpage using CSS variables

All colours are variables. The checkbox swaps their values. The page also starts in dark mode if your system prefers it.

Working demonstration

Dark mode with variables

Only four custom properties change; every element re-colours automatically.

A card that uses var(--card) for its background.
Accent button
View source code of this program 
<!-- HTML -->
<input type="checkbox" id="dm"><label class="dm-label" for="dm">Toggle dark / light mode</label>
<div class="theme"><h3>Dark mode with variables</h3><p>Only four custom properties change; every element re-colours automatically.</p>
  <div class="c">A card that uses <code>var(--card)</code> for its background.</div><a class="btn2" href="#">Accent button</a></div>

/* CSS */
.demo #dm { position: absolute; opacity: 0; }
.demo .dm-label { display: inline-block; padding: .45rem 1rem; border: 2px solid #1769b5; border-radius: 999px; cursor: pointer; font-weight: 700; margin-bottom: .8rem; }
.demo #dm:focus-visible + .dm-label { outline: 3px solid #f2c200; }
.demo .theme { --bg: #ffffff; --fg: #1c2437; --card: #f1f4fa; --accent: #1769b5; --muted: #55637d;
  background: var(--bg); color: var(--fg); padding: 1.2rem; border-radius: 12px; border: 1px solid var(--accent); transition: background .3s, color .3s; }
.demo #dm:checked ~ .theme { --bg: #0f172a; --fg: #e6ecf7; --card: #1e293b; --accent: #5eead4; --muted: #94a3b8; }
@media (prefers-color-scheme: dark) {
  .demo .theme { --bg: #0f172a; --fg: #e6ecf7; --card: #1e293b; --accent: #5eead4; --muted: #94a3b8; }
  .demo #dm:checked ~ .theme { --bg: #ffffff; --fg: #1c2437; --card: #f1f4fa; --accent: #1769b5; --muted: #55637d; }
}
.demo .theme h3 { margin-top: 0; color: var(--accent); } .demo .theme p { color: var(--muted); }
.demo .theme .c { background: var(--card); padding: 1rem; border-radius: 10px; margin: .6rem 0; }
.demo .theme a.btn2 { display: inline-block; background: var(--accent); color: var(--bg); padding: .5rem 1rem; border-radius: 8px; text-decoration: none; font-weight: 700; }
