Float and clear properties

Text wraps around a floated image, and clear / clearfix fix a parent that would otherwise collapse.

Working demonstration

An image with float: left lets the text wrap around it, like a magazine layout. A second image uses float: right. Floating was the classic way to build columns before Flexbox and Grid existed, and it is still perfect for wrapping text around images.

Parent without clearfix (collapses)

Parent with clearfix (wraps its floated children)

clear: both – this bar starts below all floats
View source code of this program 
<!-- HTML -->
<div class="clearfix">
  <img class="fl" src="../assets/images/img1.svg" alt="Mountains">
  <img class="fr" src="../assets/images/avatar.svg" alt="Avatar">
  <p>An image with <code>float: left</code> lets the text wrap around it, like a magazine layout. A second image uses <code>float: right</code>. Floating was the classic way to build columns before Flexbox and Grid existed, and it is still perfect for wrapping text around images.</p>
</div>
<h3>Parent without clearfix (collapses)</h3>
<div class="par"><div class="kid"></div><div class="kid"></div></div>
<h3 style="clear:both">Parent with clearfix (wraps its floated children)</h3>
<div class="par clearfix"><div class="kid"></div><div class="kid"></div></div>
<div class="clear-both">clear: both &ndash; this bar starts below all floats</div>

/* CSS */
.demo .fl { float: left; margin: 0 1rem .5rem 0; border-radius: 8px; width: 170px; }
.demo .fr { float: right; margin: 0 0 .5rem 1rem; width: 120px; border-radius: 50%; }
.demo .par { border: 2px solid #1769b5; padding: .6rem; margin-bottom: 1rem; }
.demo .par .kid { float: left; width: 80px; height: 50px; background: #d9481f; margin: 4px; }
.demo .clearfix::after { content: ""; display: block; clear: both; }
.demo .clear-both { clear: both; background: #f2c200; padding: .4rem; }
