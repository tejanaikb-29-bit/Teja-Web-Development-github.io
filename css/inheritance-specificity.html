CSS inheritance and specificity

Some properties flow from parent to child (inheritance). When rules conflict, specificity decides: element < class < id < inline < !important.

Working demonstration

Inheritance

Parent sets colour, font and a border.

Child paragraph inherits colour and font, but not the border.

This link uses color: inherit

This one resets with initial.

Specificity – which rule wins?

1. Element selector → red

2. Class selector beats element → blue

3. Id selector beats class → green

4. Inline style beats id/class → orange

5. !important beats inline → purple

/* CSS */
.demo .inh { color: #1769b5; font-family: Georgia, serif; font-size: 1.1rem; border: 3px solid #1769b5; padding: .6rem; }
.demo .inh a { color: inherit; }                 /* links do not inherit colour unless we ask */
.demo .inh .noinh { border: 0; color: initial; font-family: initial; }
.demo .box2 p { color: #c62828; margin: .3rem 0; }               /* element   (0,2,1) */
.demo .box2 .c { color: #1769b5; }                               /* class     (0,3,0) */
.demo .box2 #i { color: #178a4a; }                               /* id        (1,2,0) */
.demo .box2 .imp { color: #7b2cbf !important; }                  /* !important wins over inline */
