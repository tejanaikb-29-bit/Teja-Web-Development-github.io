Image hover effect

Four hover effects using only CSS: zoom, grayscale-to-colour, sliding caption and tilt.

Working demonstration

Caption slides up

View source code of this program 
<!-- HTML -->
<div class="ih">
  <div class="tile zoom"><img src="../assets/images/img1.svg" alt="Zoom"></div>
  <div class="tile gray"><img src="../assets/images/img3.svg" alt="Grayscale"></div>
  <div class="tile cap"><img src="../assets/images/img4.svg" alt="Caption"><p>Caption slides up</p></div>
  <div class="tile tilt"><img src="../assets/images/img6.svg" alt="Tilt"></div>
</div>

/* CSS */
.demo .ih { display: grid; grid-template-columns: repeat(auto-fill, minmax(220px, 1fr)); gap: 1rem; }
.demo .tile { position: relative; overflow: hidden; border-radius: 10px; height: 160px; }
.demo .tile img { width: 100%; height: 100%; object-fit: cover; display: block; transition: transform .5s, filter .5s; }
.demo .zoom:hover img { transform: scale(1.25); }
.demo .gray img { filter: grayscale(1); } .demo .gray:hover img { filter: grayscale(0); }
.demo .cap p { position: absolute; left: 0; right: 0; bottom: 0; margin: 0; padding: .7rem; background: rgba(20, 33, 61, .85); color: #fff; transform: translateY(100%); transition: transform .35s; }
.demo .cap:hover p { transform: translateY(0); }
.demo .tilt { overflow: visible; } .demo .tilt img { border-radius: 10px; } .demo .tilt:hover img { transform: rotate(-4deg) scale(1.06); box-shadow: 0 12px 24px rgba(0, 0, 0, .35); }
