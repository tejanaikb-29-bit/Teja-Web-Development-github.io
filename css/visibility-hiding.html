Visibility and hiding elements

display:none removes the element, visibility:hidden keeps its space, and opacity:0 keeps it clickable. Hover the last box to reveal its child.

Working demonstration

LeftVisibleRight
Leftdisplay:noneRight ← no gap: the element is gone
Leftvisibility:hiddenRight ← empty gap remains
Leftopacity:0Right ← gap remains and it can still be clicked
Hover this box
Now visible: visibility switched to visible

<div class="vrow"><span class="edge">Left</span><span class="mid">Visible</span><span class="edge">Right</span></div>

<div class="vrow"><span class="edge">Left</span><span class="mid hid-vis">visibility:hidden</span><span class="edge">Right</span><span style="color:#55637d;background:none"> &larr; empty gap remains</span></div>
<div class="vrow"><span class="edge">Left</span><span class="mid hid-op">opacity:0</span><span class="edge">Right</span><span style="color:#55637d;background:none"> &larr; gap remains and it can still be clicked</span></div>

/* CSS */
.demo .vrow { display: flex; align-items: stretch; margin-bottom: .8rem; }

.demo .reveal:hover .secret { visibility: visible; }
