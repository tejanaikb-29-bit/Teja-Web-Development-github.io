Three-column webpage layout using Flexbox

Left menu, centre content and right sidebar sharing the row with flex ratios 1 : 3 : 1. They stack on small screens.

Working demonstration

MenuHomeNewsContact

Main content (flex: 3)

The centre column takes three parts of the free space; the two side columns take one part each.

Ads (flex: 1)

Sponsored links

View source code of this program 
<!-- HTML -->
<div class="col3"><nav><strong>Menu</strong><a href="#">Home</a><a href="#">News</a><a href="#">Contact</a></nav>
<main><h4 style="margin-top:0">Main content (flex: 3)</h4><p>The centre column takes three parts of the free space; the two side columns take one part each.</p></main>
<aside><strong>Ads (flex: 1)</strong><p>Sponsored links</p></aside></div>

/* CSS */
.demo .col3 { display: flex; gap: .8rem; }
.demo .col3 > * { padding: 1rem; border-radius: 8px; }
.demo .col3 nav { flex: 1; background: #14213d; color: #fff; } .demo .col3 main { flex: 3; background: #eaf2ff; } .demo .col3 aside { flex: 1; background: #fff2c2; }
.demo .col3 nav a { display: block; color: #fff; padding: .2rem 0; text-decoration: none; }
@media (max-width: 640px) { .demo .col3 { flex-direction: column; } }
