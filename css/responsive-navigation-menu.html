Responsive navigation menu (CSS-only hamburger)

The menu is a horizontal bar on wide screens and a hamburger toggle below 700px, using the checkbox technique.

Working demonstration

MySite
  • Home
  • About
  • Services
  • Contact

Make the browser window narrower than 700px, then click the ☰ icon.

View source code of this program 
<!-- HTML -->
<nav class="rn"><a class="brand" href="#">MySite</a>
  <input type="checkbox" id="rn-toggle"><label class="burger" for="rn-toggle">&#9776;</label>
  <ul><li><a href="#">Home</a></li><li><a href="#">About</a></li><li><a href="#">Services</a></li><li><a href="#">Contact</a></li></ul></nav>
<p class="muted">Make the browser window narrower than 700px, then click the &#9776; icon.</p>

/* CSS */
.demo .rn { position: relative; display: flex; align-items: center; justify-content: space-between; flex-wrap: wrap; background: #14213d; padding: .4rem 1rem; border-radius: 8px; }
.demo .rn .brand { color: #f2c200; font-weight: 800; font-size: 1.2rem; text-decoration: none; }
.demo .rn ul { list-style: none; display: flex; gap: .3rem; margin: 0; padding: 0; }
.demo .rn ul a { display: block; padding: .8rem 1rem; color: #fff; text-decoration: none; border-radius: 6px; }
.demo .rn ul a:hover { background: #2b3c6b; }
.demo .rn input { display: none; }
.demo .rn .burger { display: none; color: #fff; font-size: 1.7rem; cursor: pointer; padding: .2rem .5rem; }
@media (max-width: 700px) {
  .demo .rn .burger { display: block; }
  .demo .rn ul { display: none; width: 100%; flex-direction: column; }
  .demo .rn input:checked ~ ul { display: flex; }
}
