Styled navigation bar

A horizontal navigation bar with hover effect, an active link and a right-aligned item, built with Flexbox.

Working demonstration

  • MyCollege
  • Home
  • Courses
  • Faculty
  • Contact
  • Login
View source code of this program 
<!-- HTML -->
<ul class="nav">
  <li><a class="brand" href="#">MyCollege</a></li>
  <li><a class="active" href="#">Home</a></li><li><a href="#">Courses</a></li><li><a href="#">Faculty</a></li><li><a href="#">Contact</a></li>
  <li class="right"><a href="#">Login</a></li>
</ul>

/* CSS */
.demo .nav { display: flex; align-items: center; list-style: none; margin: 0; padding: 0 .5rem; background: #14213d; border-radius: 8px; flex-wrap: wrap; }
.demo .nav a { display: block; padding: 1rem 1.1rem; color: #dbe3f0; text-decoration: none; font-weight: 600; border-bottom: 4px solid transparent; transition: .2s; }
.demo .nav a:hover { color: #fff; background: #1f3160; border-bottom-color: #f2c200; }
.demo .nav a.active { color: #14213d; background: #f2c200; }
.demo .nav .right { margin-left: auto; }
.demo .nav .brand { font-size: 1.15rem; color: #f2c200; }
