Overflow properties

visible, hidden, scroll, auto and clip, plus text-overflow: ellipsis for a single line and a multi-line clamp.

Working demonstration

overflow: visible

This text is much longer than the box so it spills outside the borders and overlaps what comes below it, which is the default behaviour.

overflow: hidden

This text is much longer than the box so the extra part is clipped and cannot be seen at all by the visitor.

overflow: scroll

Scrollbars are always shown, even when they are not needed. This text is long enough to need them anyway.

overflow: auto

Scrollbars appear only when the content does not fit. This text is long enough to need one, so scroll it.

text-overflow: ellipsis (one line)

This is a very long single line of text that will be cut off with an ellipsis.

line-clamp (two lines)

This is a long paragraph that is limited to two lines. Anything beyond the second line is hidden and replaced by an ellipsis so cards stay the same height.
