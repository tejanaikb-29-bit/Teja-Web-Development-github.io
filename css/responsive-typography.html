Responsive typography

Text that scales with the screen: rem units, viewport units, calc() and clamp(), a readable line length and stepped media queries.

Working demonstration

font-size: 4vw (no limits)

Resize the window

font-size: calc(1.2rem + 1.6vw)

Base size plus fluid growth

font-size: clamp(1.3rem, 3vw + .5rem, 2.6rem)

Fluid, but never too small or too big

Body text: clamp(1rem, .9rem + .4vw, 1.2rem), max-width: 62ch

Good body text has a comfortable size and a line length of about sixty characters. Limiting the width with the ch unit keeps lines short enough to read easily, however wide the screen is.

Media-query steps: 1rem / 1.25rem / 1.6rem

This text jumps in size at 600px and 900px

<!-- HTML -->
<div class="rt">
<h3>font-size: 4vw (no limits)</h3><p class="a">Resize the window</p>
<h3>font-size: calc(1.2rem + 1.6vw)</h3><p class="b">Base size plus fluid growth</p>
<h3>font-size: clamp(1.3rem, 3vw + .5rem, 2.6rem)</h3><p class="c">Fluid, but never too small or too big</p>
<h3>Body text: clamp(1rem, .9rem + .4vw, 1.2rem), max-width: 62ch</h3>
<p class="body">Good body text has a comfortable size and a line length of about sixty characters. Limiting the width with the ch unit keeps lines short enough to read easily, however wide the screen is.</p>
<h3>Media-query steps: 1rem / 1.25rem / 1.6rem</h3><p class="steps">This text jumps in size at 600px and 900px</p>
</div>

/* CSS */
.demo .rt h3 { margin: 1rem 0 .3rem; font: 600 .85rem Consolas, monospace; color: #55637d; }
.demo .rt .a { font-size: 4vw; margin: 0; }                          /* scales with the screen, no limits */
.demo .rt .b { font-size: calc(1.2rem + 1.6vw); margin: 0; }         /* base size plus a fluid part */
.demo .rt .c { font-size: clamp(1.3rem, 3vw + .5rem, 2.6rem); margin: 0; } /* fluid but limited */
.demo .rt .body { font-size: clamp(1rem, .9rem + .4vw, 1.2rem); line-height: 1.65; max-width: 62ch; }
.demo .rt .steps { font-size: 1rem; color: #d9481f; font-weight: 700; }
@media (min-width: 600px) { .demo .rt .steps { font-size: 1.25rem; } }
@media (min-width: 900px) { .demo .rt .steps { font-size: 1.6rem; } }
