CSS clamp(), min() and max() functions

Widths and font sizes that adapt without media queries. Resize the window and watch the bars.

Working demonstration

<!-- HTML -->
<div class="cm">
<code>width: min(90%, 500px)</code><div class="bar w1">min(90%, 500px)</div>
<code>width: max(40%, 260px)</code><div class="bar w2">max(40%, 260px)</div>
<code>width: clamp(200px, 50%, 480px)</code><div class="bar w3">clamp(200px, 50%, 480px)</div>
<code>font-size: clamp(1rem, 2.5vw, 2rem)</code><p class="f">Fluid font size</p>
<code>padding: clamp(.5rem, 2vw, 2rem)</code><div class="pad">Padding grows with the viewport but stays in range</div>
</div>

/* CSS */
.demo .cm { display: grid; gap: .3rem; }
.demo .cm code { font-size: .82rem; color: #55637d; margin-top: .6rem; }
.demo .cm div.bar { height: 38px; background: #1769b5; color: #fff; display: flex; align-items: center; padding-left: .7rem; font-weight: 700; border-radius: 6px; }
.demo .w1 { width: min(90%, 500px); }               /* the smaller of the two */
.demo .w2 { width: max(40%, 260px); background: #d9481f !important; }  /* the larger of the two */
.demo .w3 { width: clamp(200px, 50%, 480px); background: #178a4a !important; }  /* min, preferred, max */
.demo .cm .f { font-size: clamp(1rem, 2.5vw, 2rem); margin: 0; font-weight: 700; }
.demo .cm .pad { padding: clamp(.5rem, 2vw, 2rem); background: #fff2c2; }
