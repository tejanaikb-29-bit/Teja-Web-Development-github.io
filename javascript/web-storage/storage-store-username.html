Store a username using localStorage

localStorage.setItem(key, value) saves the username in the browser. It is still there after you close and reopen the page.

Working demonstration

Nothing saved yet.

Tip: press F12, open Application → Local Storage to see the stored data.

View source code of this program 
<!-- HTML -->
<div class="row"><label class="field">Username<input id="user" type="text" placeholder="e.g. asha_k"></label><button id="save">Save username</button></div><div class="out" id="out">Nothing saved yet.</div><p class="muted">Tip: press F12, open <em>Application &rarr; Local Storage</em> to see the stored data.</p>

// JavaScript
const $ = (id) => document.getElementById(id);
$('save').addEventListener('click', () => {
  const name = $('user').value.trim();
  if (!name) { $('out').textContent = 'Please type a username first.'; return; }
  localStorage.setItem('username', name);        // key, value
  $('out').textContent = `Saved "${name}" under the key "username". Refresh this page - it will still be stored.`;
});
