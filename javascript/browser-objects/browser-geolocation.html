Browser geolocation

Uses the Geolocation API to ask permission and report whether your position could be found. Pages opened from a file may be blocked by some browsers.

Working demonstration

Press the button. The browser will ask for permission.
View source code of this program 
<!-- HTML -->
<div class="row"><button id="go">Find my location</button></div><div class="out" id="out">Press the button. The browser will ask for permission.</div>

// JavaScript
const $ = (id) => document.getElementById(id);
$('go').addEventListener('click', () => {
  if (!('geolocation' in navigator)) { $('out').textContent = 'Geolocation is not supported by this browser.'; return; }
  $('out').textContent = 'Requesting location... (allow it in the permission prompt)';
  navigator.geolocation.getCurrentPosition(
    (pos) => { $('out').textContent = `Location found!\nLatitude : ${pos.coords.latitude.toFixed(5)}\nLongitude: ${pos.coords.longitude.toFixed(5)}`; },
    (err) => {
      const reasons = { 1: 'Permission denied - you blocked location access.', 2: 'Position unavailable - the device could not determine location.', 3: 'Timed out - it took too long.' };
      $('out').textContent = 'Could not get location: ' + (reasons[err.code] || err.message);
    },
    { enableHighAccuracy: true, timeout: 10000, maximumAge: 0 });
});
