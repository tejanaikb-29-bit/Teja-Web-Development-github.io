Buttons for Back, Forward and Reload

Custom browser-style toolbar buttons using history.back(), history.forward() and location.reload().

Working demonstration

Visit the JavaScript list and come back with the Back button, or press Reload to see the time change:

View source code of this program 
<!-- HTML -->
<div class="toolbar"><button id="back" title="Back">&larr;</button><button id="fwd" title="Forward">&rarr;</button><button id="rel" title="Reload">&#8635;</button><div class="addr" id="addr"></div></div>
<p>Visit the <a href="index.html">JavaScript list</a> and come back with the Back button, or press Reload to see the time change: <strong id="t"></strong></p>

/* CSS */
.demo .toolbar { display: flex; gap: .4rem; align-items: center; background: #e8edf8; padding: .6rem; border-radius: 10px; } .demo .toolbar button { background: #fff; color: #14213d; border: 1px solid #b9c3d6; font-size: 1.1rem; } .demo .toolbar .addr { flex: 1; background: #fff; border: 1px solid #b9c3d6; border-radius: 8px; padding: .4rem .7rem; font-size: .9rem; overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }

// JavaScript
const $ = (id) => document.getElementById(id);
$('addr').textContent = location.href;
$('t').textContent = new Date().toLocaleTimeString();
$('back').addEventListener('click', () => history.back());
$('fwd').addEventListener('click', () => history.forward());
$('rel').addEventListener('click', () => location.reload());
