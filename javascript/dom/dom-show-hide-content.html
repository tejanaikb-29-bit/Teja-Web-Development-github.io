Show / hide content button

A "Read more" button expands and collapses extra text, and a second button hides a whole section.

Working demonstration

JavaScript is the language of the web. It runs in every browser, powers interactive pages and, with Node.js, can even run on servers. Learning it opens the door to front-end and back-end development.

A section

This whole block can be hidden with the hidden attribute.

View source code of this program 
<!-- HTML -->
<p>JavaScript is the language of the web. <span id="more" hidden>It runs in every browser, powers interactive pages and, with Node.js, can even run on servers. Learning it opens the door to front-end and back-end development.</span></p>
<button id="rm">Read more</button>
<hr><button id="tg" class="secondary">Hide section</button>
<div id="sec" class="card" style="margin-top:.8rem"><h4 style="margin-top:0">A section</h4><p>This whole block can be hidden with the hidden attribute.</p></div>

// JavaScript
const $ = (id) => document.getElementById(id);
$('rm').addEventListener('click', () => {
  $('more').hidden = !$('more').hidden;
  $('rm').textContent = $('more').hidden ? 'Read more' : 'Read less';
});
$('tg').addEventListener('click', () => {
  $('sec').hidden = !$('sec').hidden;
  $('tg').textContent = $('sec').hidden ? 'Show section' : 'Hide section';
});
