Change the text content of an element

textContent replaces the text of an element. HTML tags typed into the box are shown as plain text.

Working demonstration

This text will be replaced.

View source code of this program 
<!-- HTML -->
<p id="target" style="font-size:1.3rem;font-weight:600">This text will be replaced.</p>
<div class="row"><input id="txt" type="text" value="<b>Hello</b> from textContent" style="flex:1;min-width:220px"><button id="go">Change textContent</button></div>

// JavaScript
const $ = (id) => document.getElementById(id);
$('go').addEventListener('click', () => {
  $('target').textContent = $('txt').value;      // tags are NOT interpreted, shown as text
});
