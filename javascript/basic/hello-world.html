Display "Hello World"

The classic first program: writes Hello World to the page, to the browser console and to an alert box.

Working demonstration

Click the button.
View source code of this program 
<!-- HTML -->
<button id="btn">Say Hello</button>
<div class="out" id="out">Click the button.</div>

// JavaScript
const $ = (id) => document.getElementById(id);
$('btn').addEventListener('click', () => {
  $('out').textContent = 'Hello World';
  console.log('Hello World');      // also visible in the browser console (press F12)
  alert('Hello World');
});
