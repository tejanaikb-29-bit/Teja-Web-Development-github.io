The input event

input fires on every change while typing, so the mirror text updates instantly. Compare with the change event.

Working demonstration

You typed:
View source code of this program 
<!-- HTML -->
<input id="inp" type="text" placeholder="Type something" style="width:100%;max-width:420px"><div class="out">You typed: <strong id="mirror"></strong></div><label class="field" style="max-width:320px">Volume: <span id="v">50</span><input id="range" type="range" min="0" max="100" value="50"></label>

// JavaScript
const $ = (id) => document.getElementById(id);
$('inp').addEventListener('input', (e) => { $('mirror').textContent = e.target.value; });
$('range').addEventListener('input', (e) => { $('v').textContent = e.target.value; });
