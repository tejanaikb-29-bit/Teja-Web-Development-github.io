The submit event

The submit event fires when a form is sent. preventDefault() stops the page from reloading so JavaScript can handle it.

Working demonstration

Submit the form to see the data.
View source code of this program 
<!-- HTML -->
<form id="f" class="row"><label class="field">Name<input id="n" type="text" required></label><label class="field">City<input id="c" type="text"></label><button type="submit">Submit</button></form><div class="out" id="out">Submit the form to see the data.</div>

// JavaScript
const $ = (id) => document.getElementById(id);
$('f').addEventListener('submit', (e) => {
  e.preventDefault();                                  // stop the normal form submission
  const data = new FormData($('f'));
  $('out').textContent = 'submit event fired.\n' + [...data.entries()].map(([k, v]) => `${k}: ${v}`).join('\n');
});
