The ondblclick event

Double-click the box to trigger the event. A single click does nothing.

Working demonstration

Double-click me
Waiting for a double click...
View source code of this program 
<!-- HTML -->
<div class="pad" id="box">Double-click me</div><div class="out" id="out">Waiting for a double click...</div>

/* CSS */
.demo .pad { display: grid; place-items: center; min-height: 120px; border: 3px dashed #8a97b3; border-radius: 12px; background: #f7f9fe; font-weight: 700; text-align: center; user-select: none; padding: 1rem; transition: background .15s, transform .1s; }

// JavaScript
const $ = (id) => document.getElementById(id);
$('box').ondblclick = () => {
  $('box').style.background = $('box').style.background === 'rgb(255, 242, 168)' ? '' : '#fff2a8';
  $('out').textContent = 'dblclick fired at ' + new Date().toLocaleTimeString();
};
