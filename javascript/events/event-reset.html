The reset event

The reset event fires when a form is reset. Here it asks for confirmation before clearing.

Working demonstration

Change the fields, then press Reset.
View source code of this program 
<!-- HTML -->
<form id="f"><div class="row"><label class="field">Name<input type="text" value="Asha"></label><label class="field">Email<input type="email" value="asha@example.com"></label></div><button type="reset" class="danger">Reset form</button></form><div class="out" id="out">Change the fields, then press Reset.</div>

// JavaScript
const $ = (id) => document.getElementById(id);
$('f').addEventListener('reset', (e) => {
  if (!confirm('Really clear all fields?')) { e.preventDefault(); $('out').textContent = 'Reset cancelled.'; return; }
  $('out').textContent = 'reset event fired - the form was cleared to its original values.';
});
