Button click event

Runs a function every time a button is clicked and counts the clicks.

Working demonstration

You have not clicked yet.
View source code of this program 
<!-- HTML -->
<button id="btn">Click me</button>
<div class="out" id="out">You have not clicked yet.</div>

// JavaScript
const $ = (id) => document.getElementById(id);
let clicks = 0;
$('btn').addEventListener('click', () => {
  clicks++;
  $('out').textContent = `Button clicked ${clicks} time${clicks === 1 ? '' : 's'}.`;
  $('btn').textContent = clicks < 5 ? 'Click again' : 'Enough!';
});
