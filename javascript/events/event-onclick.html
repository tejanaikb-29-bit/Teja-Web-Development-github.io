The onclick event

Two ways to react to a click: the onclick HTML attribute and the element.onclick property.

Working demonstration

Click a button.
View source code of this program 
<!-- HTML -->
<div class="row"><button onclick="alert('Hello from the onclick attribute!')">Attribute: onclick="..."</button>
<button id="b2" class="secondary">Property: element.onclick</button></div>
<div class="out" id="out">Click a button.</div>

// JavaScript
const $ = (id) => document.getElementById(id);
$('b2').onclick = function () {
  $('out').textContent = 'You clicked the second button (element.onclick) at ' + new Date().toLocaleTimeString();
};
