Frames and iframes

Embeds other pages inside this page with <iframe>; a link uses target to load a page into a named frame. (<frameset> is obsolete in HTML5.)

Working demonstration

1. iframe showing another page

2. Link that loads a page into a named frame

Load second page in the frame below

3. iframe with inline content (srcdoc)

View source code of this program 
<!-- HTML -->
<h3>1. iframe showing another page</h3>
<iframe src="../assets/sample-frame.html" title="Sample page"></iframe>
<h3>2. Link that loads a page into a named frame</h3>
<p><a href="../assets/sample-frame-2.html" target="myframe">Load second page in the frame below</a></p>
<iframe name="myframe" src="../assets/sample-frame.html" title="Named frame"></iframe>
<h3>3. iframe with inline content (srcdoc)</h3>
<iframe srcdoc="<h3 style='font-family:sans-serif'>Hello from srcdoc</h3><p>This HTML is written directly in the attribute.</p>" title="Inline content"></iframe>

/* CSS */
