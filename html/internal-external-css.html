Webpage with internal and external CSS styling

The same page uses three ways to add CSS: an external stylesheet (<link>), an internal <style> block, and inline style attributes.

Working demonstration

External CSS

Styled by assets/css/external-demo.css, linked with a <link> tag.

Internal CSS

Styled by a <style> block inside this page.

Inline CSS

Styled using the style attribute on the element itself.

View source code of this program 
<!-- <head> extras -->
<link rel="stylesheet" href="../assets/css/external-demo.css">

<!-- HTML -->
<div class="ext-box">
  <h3>External CSS</h3>
  <p>Styled by <code>assets/css/external-demo.css</code>, linked with a &lt;link&gt; tag.</p>
</div>
<div class="int-box">
  <h3>Internal CSS</h3>
  <p>Styled by a &lt;style&gt; block inside this page.</p>
</div>
<div style="background:#e6f6ec;border:2px solid #178a4a;border-radius:10px;padding:1rem;margin:1rem 0">
  <h3 style="margin-top:0;color:#11683a">Inline CSS</h3>
  <p>Styled using the <code>style</code> attribute on the element itself.</p>
</div>

/* CSS */
/* Internal CSS: written inside a <style> tag in the page's <head> */
.demo .int-box { background: #fff1d6; border: 2px solid #d98a00; border-radius: 10px; padding: 1rem; margin: 1rem 0; }
.demo .int-box h3 { margin-top: 0; color: #a86400; }
