Audio and video elements

Embeds local media files using the <audio> and <video> elements with built-in browser controls.

Working demonstration

Audio

Video

Attributes used: controls, width, preload. Try adding autoplay muted loop yourself.

View source code of this program 
<!-- HTML -->
<h3>Audio</h3>
<audio controls>
  <source src="../assets/media/melody.wav" type="audio/wav">
  Your browser does not support the audio element.
</audio>
<h3>Video</h3>
<video controls width="480" preload="metadata">
  <source src="../assets/media/sample.mp4" type="video/mp4">
  Your browser does not support the video element.
</video>
<p class="muted">Attributes used: <code>controls</code>, <code>width</code>, <code>preload</code>. Try adding <code>autoplay muted loop</code> yourself.</p>
