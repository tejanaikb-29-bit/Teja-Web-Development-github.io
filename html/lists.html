Ordered, unordered and description lists

Demonstrates <ol>, <ul>, nested lists and the description list (<dl>, <dt>, <dd>).

Working demonstration

Ordered list (numbers)

  1. Open the editor
  2. Write the HTML code
  3. Save the file
  4. Open it in a browser

Ordered list with type="A" and start="3"

  1. Third item
  2. Fourth item
  3. Fifth item

Unordered list (bullets) with a nested list

  • Back-end
